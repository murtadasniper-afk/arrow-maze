# Arrow Maze 🎮

A mobile-friendly arrow puzzle game.

## Features
- Arabic interface
- Multiple levels
- Coins and hints
- Responsive mobile design
- Local progress saving

## Technologies
- HTML
- CSS
- JavaScript
- Capacitor

## Project Structure
- `www/index.html` - Game interface and logic
- `package.json` - Project dependencies
- `capacitor.config.json` - Capacitor configuration
